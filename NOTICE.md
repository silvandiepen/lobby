## Dependencies

Dependencies are fetched by npm, cargo and SwiftPM and are not part of this repository:

- **npm** (server and introducer at run time): `hono`, `@hono/node-server`, `bonjour-service`,
  `multicast-dns`, `ws`. All MIT. The push relay has no run-time dependencies. Development tools
  (TypeScript, ESLint, Prettier, Vitest, Miniflare) are not shipped.
- **Rust crates** (`lobby-direct`): `quinn`, `rustls`, `ring`, `tokio`, `socket2`, `serde_json`,
  `base64` and what they depend on: MIT, Apache-2.0, ISC and similar permissive licences.
- **Apple apps and LobbyKit**: no third-party Swift packages.
- **At run time, not bundled**: ffmpeg and ffprobe (LGPL/GPL, from the system), Python with
  `pyatv` (MIT) for waking an Apple TV, when used.

Every server release archive carries `LICENSES/LICENSE` (this repository's MPL-2.0 text) and
`LICENSES/THIRD-PARTY-NOTICES.txt`, generated by `tools/release/build.ts` with the exact licence
texts of the Node.js runtime, the npm packages and the crates in that archive.

## Services

- **TMDB.** When a server has a TMDB key, titles, posters and summaries come from The Movie
  Database. This product uses the TMDB API but is not endorsed or certified by TMDB. Each server
  operator brings their own key and follows TMDB's terms.
- **Demo library.** `tools/demo` downloads open movies from the Blender Foundation (CC BY) at
  setup time; none of them is in this repository. `tools/demo/README.md` lists their licences and
  attributions.
