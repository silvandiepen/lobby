# Viewer avatars

The 32 original avatars a viewer can pick, 600 px. The file name is the avatar id; the app's copy is
`apps/apple/Shared/Avatars.xcassets`. Cut round in the app. None is based on an existing character.

They were made with AI image generation (OpenAI, through Codex). **All rights reserved**, not
covered by the code licence: see [`assets/LICENSE-ART`](../../../assets/LICENSE-ART). Whether they
can be licensed to others is still being checked. A fork replaces them with its own set.
